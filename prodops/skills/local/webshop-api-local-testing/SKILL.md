# Skill: webshop-api-local-testing

## Objetivo

Executar e validar os testes locais do webshop-api.

## Quando utilizar

Antes de abrir PR, para garantir que todos os testes locais passam.

## Entradas

- Código implementado na feature branch

## Saídas

- Resultado dos testes locais (pass/fail)

## Execução

```bash
# Adapte com o comando de teste do projeto
./mvnw test
# ou
./gradlew test
```
