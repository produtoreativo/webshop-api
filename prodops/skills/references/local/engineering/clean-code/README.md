# Clean Code — webshop-api

Guia local de qualidade de código para este produto. Adapte com convenções específicas do projeto.

## Princípios aplicados

- Nomes expressivos para classes, métodos e variáveis
- Funções pequenas com responsabilidade única
- Ausência de comentários explicando o *quê* — o código deve ser autoexplicativo
- Testes como documentação executável
